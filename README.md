# JavaScript

This repository contains my JavaScript learning journey, from basic exercises and practice programs to DOM manipulation utilities and small web apps.

I'm using it to keep track of what I learn, experiment with different ideas, and build things as I get more comfortable with web development.


WHAT"S INSIDE

The repository is organized into different practice focus areas:

1. Added Number & Inputed sum : focus on dynamic input handling, type casting, and mathematical evaluation.
2. Adding list & To-Do List: focus on DOM node creation, list appending, and task state management.
3. Click Me, Greeter, & peekaboo: focus on event listeners, user feedback loops, and visibility toggles.
4. Color changer, Position Practice, & character count: focus on real-time UI updates, style manipulation, and string tracking.
5. Counter & Password: focus on state control, UI bounds logic, and length checks.


WHAT I AM LEARNING

Some of the main areas covered in this repository include:

* JavaScript fundamentals 
* DOM selection and dynamic element manipulation
* Event architecture (`click`, `input`, form handling)
* State tracking without external libraries
* Building clean user interface interactions
* Writing organized web logic

This repository is still a work in progress. As I learn more, I'll keep adding new experiments, DOM practice projects, and larger programs.


WHY THIS EXISTS

I'm keeping this repository public so I can see how my code changes over time instead of letting everything disappear into random folders on my computer.

The goal is simple: learn by building, make mistakes, figure them out, and gradually write better code.
